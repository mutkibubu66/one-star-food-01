A tiny pure-stdlib Python program that writes exactly one sentence to a file: an alien tourist's one-star review of planet Earth that still slips in a real compliment about the food. Before writing, it checks the sentence is between 1 and 200 characters long, is a single line, and is not only whitespace.

## Run it

```sh
python3 main.py
```

By default the sentence is written to `/output/entry.txt`. Pass a different path as an argument (`python3 main.py /tmp/entry.txt`) or set the `ENTRY_OUTPUT` environment variable to override it.
